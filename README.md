# Проект «Аргус» — Нейросеть мониторинга курения и возраста

Система компьютерного зрения и видеоаналитики на базе АПК «Безопасный город» для автоматического определения возраста человека и выявления фактов курения (сигареты, электронные испарители, вейпы, pod-системы).

## ✨ Возможности

- **Загрузка фото**: перетаскивание (Drag & Drop), выбор файла или захват кадра с веб-камеры.
- **Анализ нейросетью**: детекция сигарет, вейпов, жеста затяжки («рука у рта») и облака пара/дыма.
- **Оценка возраста**: вычисление биологического возраста с доверительным интервалом (например, `14–16 лет`) и определение совершеннолетия (`<18` или `18+`).
- **Безопасность API-ключа**: ключ API хранится исключительно на стороне бэкенда (`server.ts`) в защищенных переменных окружения и никогда не передается клиенту в браузер.

## 🚀 Быстрый запуск

### 1. Клонирование репозитория
```bash
git clone https://github.com/ВАШ_ЛОГИН/argus-ai.git
cd argus-ai
```

### 2. Установка зависимостей
```bash
npm install
```

### 3. Настройка API-ключа
Создайте файл `.env` в корне проекта (файл уже добавлен в `.gitignore` и защищен от попадания на GitHub):
```bash
cp .env.example .env
```
Откройте `.env` и вставьте ваш ключ Google Gemini:
```env
GEMINI_API_KEY="ВАШ_КЛЮЧ_GEMINI"
```
*(Получить бесплатный ключ можно в [Google AI Studio](https://aistudio.google.com/app/apikey))*

### 4. Запуск в режиме разработки
```bash
npm run dev
```
Откройте браузер по адресу: `http://localhost:3000`

### 5. Сборка для продакшена
```bash
npm run build
npm start
```

---

## 🔒 Безопасность и защита ключа

1. Файл `.env` с реальным ключом **никогда не попадает в Git** благодаря настройке `.gitignore`.
2. В репозитории опубликован только безопасный шаблон `.env.example`.
3. Все запросы к нейросети выполняются через защищенный серверный эндпоинт `/api/analyze`. Клиентский код никогда не имеет доступа к API-ключу.

## Технические примечания по видео и API

- Загруженное видео открывается как локальный предпросмотр в браузере через временный `blob:` URL. Файл не отправляется на сервер и не обрабатывается автоматически.
- Для воспроизведения в браузерах предпочтительны MP4 с H.264/AAC или WebM с VP8/VP9. Контейнер `.mp4` сам по себе не гарантирует совместимость: важны кодеки внутри файла.
- Временный URL видео освобождается при выборе другого файла или сбросе страницы.
- Ошибки сети, HTTP-ошибки и некорректные ответы `/api/analyze` теперь показываются явно. При недоступном API приложение больше не подменяет ответ синтетической локальной оценкой.
- `/api/health` сообщает только факт конфигурации API-ключа и не раскрывает upstream URL или модель.
- Для production команда запуска использует `tsx server.ts`; `tsx` включён в обычные зависимости. На Render задайте `GEMINI_API_KEY` в Environment, не добавляйте настоящий ключ в GitHub.
