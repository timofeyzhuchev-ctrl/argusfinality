# Уведомления о заявках в личный Telegram администратора

1. В своём Telegram откройте @Argusboss_bot, нажмите `/start`, затем отправьте `/myid`.
2. Бот ответит числовым ID вашего личного чата. Скопируйте только число.
3. В Render откройте веб-сервис Argus → **Environment** → **Add Environment Variable**.
4. Добавьте `TELEGRAM_ADMIN_CHAT_ID` = ваш числовой ID. Не вставляйте токен бота в чат или файлы.
5. Загрузите код обновления в репозиторий проекта и дождитесь успешного развёртывания на Render. Убедитесь, что новый код и переменная окружения применены.
6. В отдельном Telegram-аккаунте отправьте боту `/add`, заполните заявку, прикрепите фото, затем `/save`. В ваш личный чат с ботом придёт фото и данные заявки.

**Важно:** Telegram-бот не может первым написать пользователю, поэтому до проверки нажмите `/start` в своём личном чате с ботом.

Уведомления отправляются **только о заявках, сохранённых через `/save`**. Фото и видео, присланные для обычного анализа, автоматически администрации не пересылаются. Если `TELEGRAM_ADMIN_CHAT_ID` не указан или задан неверно, заявка всё равно сохраняется в БД, но сообщение в Telegram не приходит. Для защиты персональных данных сообщите пользователям, что фото и данные сохранённых заявок будут переданы администратору.

Если ваш рабочий репозиторий содержит файлы с теми же именами, замените их соответствующими файлами из архива. В комплекте **только обновление**, не полный сайт и не весь сервер.
