# Обновление Telegram-бота «Аргус» · 6 ноября 2026

Это обновление для ранее установленной версии argus-telegram-design.
В архиве только файлы бота и тесты. Другие файлы сайта удалять не нужно.

## Как установить

1. Распакуйте архив.
2. Откройте корень репозитория argusfinality на GitHub → Add file → Upload files.
3. Перетащите папки src и tests из этого архива. Сохраняйте их структуру:
   файлы telegramBot.ts и другие должны лежать в src/server/, не в корне.
4. Сохраните изменения в ветку, которую разворачивает Render.
   При включённом Auto-Deploy дождитесь успешной сборки. В противном случае
   запустите развёртывание последнего коммита через Render.
5. После запуска отправьте боту /start и новое фото.

Новые ключи, зависимости, изменения схемы PostgreSQL не требуются.
node_modules и dist не загружаются. Старые кнопки добавления из результатов
после перезапуска недействительны: отправьте фото заново.

## Что изменилось

- Подробный отчёт по фото: примерный возраст и диапазон, курение/вейпинг,
  алкоголь, рука у рта, дым/пар, обнаруженные объекты и связное пояснение.
- Проценты подписаны как уверенность модели, а не доказанная точность.
- Видео: эпизоды с временем, описаниями и возрастом, если он получен для эпизода.
- Сообщение обработки обновляется раз в 2 секунды; показывает стадию и время.
  Исправлена несовместимость редактирования сообщения с обычной клавиатурой.
  При ограничениях Telegram анимация замедляется, анализ продолжает работу.
- После фото с обнаруженным человеком — кнопка «Добавить человека с этого фото».
  Она открывает заполнение записи; фото прикрепляется автоматически.
  Кнопка привязана к исходному чату и действует 15 минут.
- По-прежнему нужно ввести настоящую дату рождения: примерный возраст модели
  не переносится в базу как паспортные данные.
- Чтение сообщений Telegram больше не ждёт окончания анализа.
  Одновременно обрабатываются максимум два файла, по одному на чат.
  Остальные получают сообщение о занятости вместо бесконечного ожидания.
  Искусственная пауза между отправками уменьшена с 30 до 5 секунд.

При сбое получения исходного фото или превышении 2 МБ форма попросит новое фото,
сохранив введённые поля. Подтверждение сохранения по-прежнему обязательно.
Фактическое время ответа модели и пробуждение спящего хостинга могут оставаться
долгими: ускорен отклик бота и убрано ожидание чужих запросов, модель не заменена.

Поиск личности по базе ещё не реализован. Отчёт честно сообщает это и не заявляет,
что нарушения закона доказаны или исключены. Анализ фото и видео сайта не изменён.

## Проверка

Пройдены проверка TypeScript, production-сборка Vite и 22 теста: отчёты,
экранирование, ограничения длины, анимация и её остановка, параллельные чаты,
кнопки, добавление с исходным фото, повторное сохранение и ошибки.

Команды в полной папке проекта:

```text
npm run lint
npm run build
npx tsx --test tests/telegramRegistration.test.mjs tests/telegramPresentation.test.mjs tests/telegramPrefill.test.mjs tests/telegramDispatch.test.mjs
```

Проверка с вашим токеном Telegram и базой Render не проводилась; они не доступны
среде разработки. После обновления проверьте:
1. /start и меню во время анализа;
2. движение индикатора до появления отчёта;
3. возраст и признаки в отчёте;
4. кнопку добавления, заполнение полей и /save;
5. появление записи в административной панели сайта;
6. прежний анализ фото и видео сайта.
